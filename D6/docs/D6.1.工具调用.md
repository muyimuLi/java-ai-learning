# 工具调用
先使用`@Tool`注解暴露工具接口，此注解标注在方法上，再使用ChatClient的`tools()`将工具注册到ChatClient上

步骤：
1. 定义工具
2. 将工具注册到ChatClient上
3. ChatClient自动注册一个`ToolCallingAdvisor`驱动工具调用循环
4. 模型决定调用哪个工具
5. 由`ToolCallingManager`来执行工具调用

组件：
- ToolCallingAdvisor：驱动工具调用循环，因为工具调用可能会拿到正确数据为止
- ToolCallingManager：执行工具调用

OrderTools:
```java
@Slf4j
public class OrderTools {
    @Tool(name = "queryOrderStatus", description = "查询订单状态时使用此工具")
    public String queryOrderStatus() {
        log.info("查询订单状态");
        return "待收货";
    }

    @Tool(name = "queryLogistics", description = "查询物流时使用此工具")
    public String queryLogistics() {
        log.info("查询物流");
        return "快递已到达广东省深圳市";
    }
}
```

MyController:
```java
@RestController
public class MyController {

    @Resource
    private ChatClient chatClient;

    @GetMapping(value = "/ai")
    public String generate(@RequestParam("userInput") String userInput) {
        return chatClient.prompt()
                .tools(new OrderTools())
                .user(userInput)
                .call()
                .content();
    }
}
```

接口调用：
```text
http://localhost:8080/ai?userInput=订单 A123 到哪了
```

## 三种定义方式
### @Tool注解
同上示例

注解中的两个参数：
- returnDirect：调用结果不返回给模型，直接返回给框架
- resultConverter：对结果进行转换

### 编程式定义
通过`MethodToolCallback`实现

工具不显式声明`@Tool`注解

```java
@GetMapping(value = "/ai")
    public String generate(@RequestParam("userInput") String userInput) {
        Method method = ReflectionUtils.findMethod(OrderTools.class, "queryLogistics");

        MethodToolCallback methodToolCallback = MethodToolCallback.builder()
                .toolDefinition(ToolDefinition.builder()
                        .name("queryLogistics")
                        .description("查询物流时使用此工具")
                        .inputSchema("{\"type\":\"object\"}")
                        .build())
                .toolMethod(method)
                .toolObject(new OrderTools())
                .build();

        return chatClient.prompt()
                .tools(methodToolCallback)
                .user(userInput)
                .call()
                .content();
    }
```

模型输出：
```text
您的订单 A123 物流信息如下：

📦 **最新状态**：快递已到达广东省深圳市

如需查询更详细的配送进度或预计送达时间，请告诉我，我可以帮您进一步跟进。
```

### 函数式定义
通过`FunctionToolCallback`实现

工具不显示声明`@Tool`注解

```java
@GetMapping(value = "/ai")
    public String generate(@RequestParam("userInput") String userInput) {
        FunctionToolCallback<OrderTools, String> functionToolCallback = FunctionToolCallback.builder("queryOrderStatus", OrderTools::queryOrderStatus)
                .description("查询订单状态时使用此工具")
                .inputType(OrderTools.class)
                .build();

        return chatClient.prompt()
                .tools(functionToolCallback)
                .user(userInput)
                .call()
                .content();
    }
```

模型输出：
```text
查询结果：订单 **A123** 当前状态为 **待收货**（包裹已在配送途中，等待签收）。

小提示：我使用的查询工具没有接收订单号的参数，所以返回结果是系统给出的当前订单状态，无法从接口层面二次确认它一定对应 A123。如果你名下有多个订单，建议在订单详情页再核对一下；需要我帮你做别的查询也可以告诉我。
```

### 原理
Spring AI通过`ToolCallback`来发现工具，通过`ToolCallbackResolver`来暴露工具

`@Tool`、`MethodToolCallback`、`FunctionToolCallback`都相当于定义了一个`ToolCallback`Bean

也可以自定义`ToolCallback`Bean

OrderToolsConfig：
```java
@Configuration(proxyBeanMethods = false)
public class OrderToolsConfig {
    @Bean
    ToolCallback toolCallback() {
        return FunctionToolCallback.builder("queryOrderStatus", OrderTools::queryOrderStatus)
                .description("查询订单状态时使用此工具")
                .inputType(OrderTools.class)
                .build();
    }
}
```

MyController：
```java
@RestController
public class MyController {

    @Resource
    private ChatClient chatClient;

    @Autowired
    private ToolCallback toolCallback;

    @GetMapping(value = "/ai")
    public String generate(@RequestParam("userInput") String userInput) {
        return chatClient.prompt()
                .tools(toolCallback)
                .user(userInput)
                .call()
                .content();
    }

}
```
