# 工具调用
先使用`@Tool`注解暴露工具接口，此注解标注在方法上，再使用ChatClient的`tools()`将工具注册到ChatClient上

步骤：
1. 定义工具
2. 将工具注册到ChatClient上
3. ChatClient自动注册一个`ToolCallingAdvisor`驱动工具调用循环
4. 模型决定调用哪个工具
5. 由`ToolCallingManager`来执行工具调用

组件：
- ToolCallingAdvisor：驱动工具调用循环，因为工具调用可能会拿到正确数据为止
- ToolCallingManager：执行工具调用

OrderTools:
```java
@Slf4j
public class OrderTools {
    @Tool(name = "queryOrderStatus", description = "查询订单状态时使用此工具")
    public String queryOrderStatus(@ToolParam(description = "订单号，如 A123") String orderId) {
        log.info("查询订单状态, orderId = {}", orderId);
        return switch (orderId) {
            case "A123" -> "待收货";
            case "A456" -> "待发货";
            default -> "订单不存在";
        };
    }

    @Tool(name = "queryLogistics", description = "查询物流时使用此工具")
    public String queryLogistics(@ToolParam(description = "订单号，如 A123") String orderId) {
        log.info("查询物流, orderId = {}", orderId);
        return switch (orderId) {
            case "A123" -> "快递已到达广东省深圳市";
            case "A456" -> "快递待发货";
            default -> "物流信息不存在";
        };
    }
}
```

MyController:
```java
@RestController
public class MyController {

    @Resource
    private ChatClient chatClient;

    @GetMapping(value = "/ai")
    public String generate(@RequestParam("userInput") String userInput) {
        return chatClient.prompt()
                .tools(new OrderTools())
                .user(userInput)
                .call()
                .content();
    }
}
```

接口调用：
```text
http://localhost:8080/ai?userInput=订单 A123 到哪了
```

日志中包含工具调用信息：
```text
2026-10-12T21:57:49.002+08:00  INFO 7304 --- [ai-demo] [nio-8080-exec-1] c.lsj.ai_demo.domain.ai.tool.OrderTools  : 查询物流, orderId = A123
```

模型输出：
```text
订单 A123 的物流信息显示：**快递已到达广东省深圳市**。

需要我帮您查一下订单当前的状态吗？
```

## 三种定义方式
### @Tool注解
同上示例

注解中的两个参数：
- returnDirect：调用结果不返回给模型，直接返回给框架
- resultConverter：对结果进行转换

### 编程式定义
通过`MethodToolCallback`实现

工具不显式声明`@Tool`注解

```java
@RestController
public class MyController {

    @Resource
    private ChatClient chatClient;

    @GetMapping(value = "/ai")
    public String generate(@RequestParam("userInput") String userInput) {
        Method method = ReflectionUtils.findMethod(OrderTools.class, "queryLogistics", String.class);

        MethodToolCallback methodToolCallback = MethodToolCallback.builder()
                .toolDefinition(ToolDefinition.builder()
                        .name("queryLogistics")
                        .description("查询物流时使用此工具")
                        .inputSchema("""
                                {
                                  "type": "object",
                                  "properties": {
                                    "orderId": {
                                      "type": "string",
                                      "description": "订单号，例如 A123 或 A456"
                                    }
                                  },
                                  "required": ["orderId"],
                                  "additionalProperties": false
                                }
                                """)
                        .build())
                .toolMethod(method)
                .toolObject(new OrderTools())
                .build();

        return chatClient.prompt()
                .tools(methodToolCallback)
                .user(userInput)
                .call()
                .content();
    }

}
```

接口调用：
```text
http://localhost:8080/ai?userInput=订单 A456 到哪了
```

模型输出：
```text
订单 A456 目前的状态是：**快递待发货**。

也就是说包裹还没有交给快递公司揽收，暂时还查不到物流轨迹。建议你稍后再查询，或者直接联系卖家确认发货时间。需要我帮你查其他订单吗？
```

### 函数式定义
通过`FunctionToolCallback`实现

工具不显示声明`@Tool`注解

新增一个inputType的承载类，同时它也能带参数：
```java
public record OrderStatusRequest(String orderId) {
}
```

```java
@RestController
public class MyController {

    @Resource
    private ChatClient chatClient;

    @GetMapping(value = "/ai")
    public String generate(@RequestParam("userInput") String userInput) {
        FunctionToolCallback<OrderStatusRequest, String> functionToolCallback = FunctionToolCallback.builder("queryOrderStatus", (OrderStatusRequest request) -> new OrderTools().queryOrderStatus(request.orderId()))
                .description("查询订单状态时使用此工具")
                .inputType(OrderStatusRequest.class)
                .build();

        return chatClient.prompt()
                .tools(functionToolCallback)
                .user(userInput)
                .call()
                .content();
    }

}
```

接口调用：
```text
http://localhost:8080/ai?userInput=订单 A456 的状态是什么
```

模型输出：
```text
订单 **A456** 的当前状态是：**待发货**。

如需了解预计发货时间或其他帮助，请告诉我。
```

### 原理
Spring AI通过`ToolCallback`来发现工具，通过`ToolCallbackResolver`来暴露工具

`@Tool`、`MethodToolCallback`、`FunctionToolCallback`都相当于定义了一个`ToolCallback`Bean

也可以自定义`ToolCallback`Bean

OrderToolsConfig：
```java
@Configuration(proxyBeanMethods = false)
public class OrderToolsConfig {
    @Bean
    ToolCallback toolCallback() {
        return FunctionToolCallback<OrderStatusRequest, String> functionToolCallback = FunctionToolCallback.builder("queryOrderStatus", (OrderStatusRequest request) -> new OrderTools().queryOrderStatus(request.orderId()))
                .description("查询订单状态时使用此工具")
                .inputType(OrderStatusRequest.class)
                .build();
    }
}
```

MyController：
```java
@RestController
public class MyController {

    @Resource
    private ChatClient chatClient;

    @Autowired
    private ToolCallback toolCallback;

    @GetMapping(value = "/ai")
    public String generate(@RequestParam("userInput") String userInput) {
        return chatClient.prompt()
                .tools(toolCallback)
                .user(userInput)
                .call()
                .content();
    }

}
```
