# 使用多个兼容OpenAI的模型
由于模型不同，因此不能使用Spring Boot自动配置的同一个ChatModel，所以要创建多个ChatModel

通过`OpenAiChatModel`和`OpenAiChatOptions`来指定模型的`baseUrl`、`apiKey`、`model`

再将ChatModel作为参数传递到ChatClient中构造

```java
public class ChatModelTest {
    @Test
    public void chatModelTest() {
        OpenAiChatModel openaiChatModel = OpenAiChatModel.builder().options(OpenAiChatOptions.builder().baseUrl("https://api.openai.com").apiKey(System.getenv("OPENAI_API_KEY")).model("gpt-5").build()).build();

        OpenAiChatModel deepseekChatModel = OpenAiChatModel.builder().options(OpenAiChatOptions.builder().baseUrl("https://api.deepseek.com").apiKey(System.getenv("DEEPSEEK_API_KEY")).model("deepseek-flash").build()).build();

        System.out.println("openai: " + ChatClient.builder(openaiChatModel).build().prompt("你好").call().content());
        System.out.println("deepseek:" + ChatClient.builder(deepseekChatModel).build().prompt("你好").call().content());
    }
}
```
