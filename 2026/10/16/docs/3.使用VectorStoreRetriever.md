# 使用VectorStoreRetriever
来自`spring-ai-starter-vector-store-pgvector`包

`VectorStoreRetriever`同样使用的是检索组件，而不是通过`Advisor`包装的形式

## 示例代码
pom.xml：
```xml
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-starter-vector-store-pgvector</artifactId>
</dependency>
```

java代码参考[1.接入QuestionAnswerAdvisors.md](1.%E6%8E%A5%E5%85%A5QuestionAnswerAdvisors.md)

`VectorStoreRetriever`和`VectorStoreDocumentRetriever`都是向量检索，检索出相似片段
