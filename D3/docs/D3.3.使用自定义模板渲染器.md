# 使用自定义模板渲染器
如果希望提示词模板中的占位符不适用`{}`而使用其他字符的话，可以使用`TemplateRenderer`接口来自定义占位符

将`TemplateRenderer`作为`PromptTemplate`中`render()`方法的参数即可达到自定义渲染的效果

`TemplateRenderer`有两个实现类：
- StTemplateRenderer：字符串渲染
- NoOpTemplateRenderer：不做任何渲染

![3.2.TemplateRenderer类继承关系.png](imgs/3.2.TemplateRenderer%E7%B1%BB%E7%BB%A7%E6%89%BF%E5%85%B3%E7%B3%BB.png)

比如以下代码将`{}`改成了`<>`

```java
@RestController
public class MyController {
    private final ChatModel chatModel;

    public MyController(ChatModel chatModel) {
        this.chatModel = chatModel;
    }

    @PostMapping("/ai")
    public String generate() {
        PromptTemplate promptTemplate = PromptTemplate.builder()
                .renderer(StTemplateRenderer.builder().startDelimiterToken('<').endDelimiterToken('>').build())
                .template("""
                        Tell me the names of 5 movies whose soundtrack was composed by <composer>.
                        """)
                .build();

        String prompt = promptTemplate.render(Map.of("composer", "John Williams"));

        return chatModel.call(prompt);

    }

}
```
