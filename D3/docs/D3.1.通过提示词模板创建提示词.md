# 通过提示词模板创建提示词 
几个重要的类：
- 提示词：`Prompt`
- 消息：`Message`
- 角色类型：`MessageType`
- 提示词模板：`PromptTemplate`
- 提示词模板渲染器：`TemplateRenderer`

## 1. 创建提示词模板
通过`PromptTemplate`来创建提示词模板

## 2. 创建提示词
通过调用`PromptTemplate`的`create()`方法来创建提示词

## 3. 调用模型
通过`ChatModel`的`call()`方法来调用模型

## 4. 代码示例
```java
@RestController
public class MyController {
    private final ChatModel chatModel;

    public MyController(ChatModel chatModel) {
        this.chatModel = chatModel;
    }

    @PostMapping("/ai")
    public Generation generate() {
        // 1. 创建提示词模板
        PromptTemplate promptTemplate = new PromptTemplate("Tell me a {adjective} joke about {topic}");

        // 2. 通过模板创建提示词
        Prompt prompt = promptTemplate.create(Map.of("adjective", "funny", "topic", "game"));

        // 3. 调用模型
        return chatModel.call(prompt).getResult();
    }

}
```
